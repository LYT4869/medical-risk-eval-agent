# treeSem Agent 路由语义契约

## 目标

本契约定义“用户自然语言请求属于哪个业务主任务”，用于约束规则路由、可选语义路由和评测标注。
它不定义权限；Tool 最终能否执行仍由 Schema、Capability、RBAC 和资源归属决定。

规则路由只承担高精度快路径：证据不足、指代不清或包含多个独立任务时返回 `UNKNOWN`，交给受约束的 Open Agent。

## 六类业务主任务

| Scope | 用户主目标 | 最小证据 | 可吸收的工作流依赖 |
|---|---|---|---|
| `prediction` | 对演示样本执行一次新预测 | 预测动作和演示样本对象，或明确样本编号 | 无 |
| `summary` | 读取已经保存的标签、概率、置信度或模型版本 | 读取动作、预测事实对象和已有预测引用 | 读取预测记录 |
| `explanation` | 解释一条已有预测的重要特征或决策路径 | 解释动作/细节和已有预测引用 | 同一预测的摘要 |
| `history` | 列出当前会话中保存的预测记录 | 列表/读取动作和历史记录对象 | 无 |
| `comparison` | 比较两条已经保存的预测 | 比较动作和多条/前后预测引用 | 定位历史记录、读取被比较记录的摘要 |
| `knowledge` | 检索一般模型知识或产后出血知识 | 检索/科普动作和模型或临床知识对象 | MCP 知识检索 |

## 主任务与依赖

以下表达仍属于一个主任务：

```text
比较最近两次预测
给出最新置信度，并与上一条记录比较
先从历史中找到最近两条，再比较结果
解释当前预测的标签、概率和决策路径
```

原因是 History、Summary 在这些句子中只用于定位或展示 Comparison、Explanation 的必要数据，不是独立目标。

## 真正的多意图

以下组合包含两个独立交付目标，确定性路由必须返回 `UNKNOWN`：

```text
prediction + explanation
prediction + history
explanation + comparison
explanation + knowledge
comparison + knowledge
history + knowledge
三个及以上独立 Scope
```

代表性表达：

```text
运行样本 3，然后解释刚生成的结果
解释当前预测，再查找产后出血指南
比较最近两次预测，并检索模型限制
列出历史记录，然后预测演示样本 5
比较结果并分别解释两条决策路径
```

## Unknown 与指代不足

以下情况返回 `UNKNOWN`：

- 请求不属于六类业务任务；
- 只出现对象名，没有足够动作和上下文；
- “这个”“当前情况”等引用无法绑定业务对象；
- 同时存在多个无法通过依赖关系吸收的完整业务目标；
- 路由器没有足够证据做高置信判断。

`UNKNOWN` 不是错误响应，而是路由器主动弃权。请求随后进入受 Tool 白名单、步骤上限和总超时约束的 Open Agent。

## 安全边界

业务 Taxonomy 不包含权限结论。处理顺序固定为：

```text
SafetyPolicy 风险预筛
  → 业务路由
  → Workflow / Open Agent
  → Tool Schema 与白名单
  → C++ Capability、RBAC 和资源归属
```

安全风险预筛漏判不代表获得执行权限；业务路由命中也不能扩大 Capability。

## 评测口径

必须分别统计：

- 正确确定性路由；
- 已知意图弃权；
- 已知意图进入错误 Workflow；
- Unknown 被强制路由；
- 多意图被强制路由；
- 安全风险预筛错误。

旧 240 条 Heldout 已经用于一次性晋级判断，后续只能作为历史失败证据，不能继续用于调参或宣称新版本泛化提升。
