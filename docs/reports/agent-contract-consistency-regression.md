# Agent 契约一致性修复与真实定向回归

日期：2026-09-14。基线：`a18e7ae`；隔离分支：`test/composite-response-semantics`。

## 结论

本轮补齐“上次摘要”的历史依赖，把 Router 的纯跨字段校验和执行层绑定接到同一份契约，并复用原两次尝试预算进行修复。未新增 Router Schema 字段、模型、Planner、Executor 或 Reflection 子系统；未切默认、合并或推送。

真实模型的 6 条定向请求在自动最低契约评分下通过，但人工检查发现：**标签含义的原场景仍漏答，不能宣布三个问题全部闭环或整体成功率 100%。** 原 48 场景成绩和评分不变。

## 修复的机制，而不是特殊问句

### 目标定位与内容读取分开

上次解释已有“查当前会话头部历史→取第二条真实 ID→读取 explanation”的路径；上次摘要此前被目标允许表拒绝。本轮让 summary 同样支持 `previous_prediction`，复用原有 `LATEST_TWO_HISTORY` 和 `PREVIOUS_FROM_HISTORY` 参数来源，再读取 summary。

没有让 Router 生成业务 ID，没有把当前预测当成上次，也没有为每种问法创建不同流程。该稳定流程可以直接与已有知识 Workflow 组合。历史不足时用目标中性的“无法取得上一次结果”，grounding 为空，不能引用依赖查询中唯一的当前记录。

### 同一份跨字段契约，同一份尝试预算

类型正确不等于字段组合正确。本轮抽出共享的纯 target/aspect/knowledge_scope 校验，Router 在解析后调用，执行层绑定时仍调用。错误反馈仅包含安全原因码和根据同一份契约生成的允许枚举，不含错误响应正文、临床事实或凭据。

传输重试、Schema 修复和跨字段修复都消耗原配置的最多两次总尝试，不增加第三次调用，不在契约失败后降级开放 Agent。候选索引、原文证据、真实记录存在性和权限仍在原业务边界处理，不作为该纯校验的职责。

复审发现一处提前返回的不一致：业务层会消解“单 explicit＋missing target”，Router 却跳过该状态的契约校验。已用失败先行测试复现，抽出共享的可消解状态判定，确保该状态的非法 Aspect 仍进入修复；实际候选索引不由 Router 修复。

### 知识完成度不冒充答案完成度

Finalizer 上下文增量记录全局知识证据的 `retrieved / not_found / unavailable` 状态，同时固定 `answer_coverage=not_verified`。这是运行时检索事实，不是 Router 字段，也不表示每个知识子问题都有答案或每条资料都相关。

最终提示要求只回答资料或权威元数据明确支持的内容；缺少某部分依据时保留已取得的业务结果，并明确指出未回答的部分，不能用 AUC、PPH 术语等泛泛知识代替标签编码说明。

这里没有引入语义覆盖审核器，因此**目前该要求仍依赖 LLM 遵守，不能宣称代码已经确定性识别所有知识漏答。** 没有猜测标签的临床含义，没有修改合成证据或标准答案把场景变成有答案。

## 真实定向结果

模型：`qwen3.7-plus-2026-05-26`，关闭思考；Router 输出 384 Token、单次 6 秒／总 13 秒；回答上限 1024 Token。上述超时属于这轮评测配置，不是默认部署切换。

集合：原已揭晓 021、026、028，加三条人工编写的新表达。沿用原业务记录、知识 excerpt 和 Gold；这是定向回归与表达变体，不是全新未揭晓 Heldout，更不是进程级 Gateway/MySQL/ONNX/MCP 测试。

| 场景 | 实际行为 | 单人人工检查 |
|---|---|---|
| 021 上一份标签和概率 | history→get_prediction，取真实上次 ID `pred_…0040`，标签 0、概率 0.4 | 完成；没有读错当前记录。 |
| 026 比较＋解释标签含义 | 按时间解释 0.8→0.3、差值 -0.5；检索后只介绍 PPH、AUC 等泛泛知识 | **漏答仍存在**：既没定义编码，也没明确承认编码依据缺失。 |
| 028 比较＋概率变化的临床含义 | 比较＋model knowledge，说明 0.51→0.49 不直接等于病情变化 | 完成；没有非法 Aspect 或开放规划。 |
| 上次摘要的新表达 | 明确“不读最新”，仍用 history→真实上次 summary | 完成。 |
| 比较与知识的新表达 | 目标、差值、引用正确，明确不能直接推断病情改变 | 主任务完成，但额外推测“细微输入→叶子变化→风险评分波动”，该机制解释没有足够证据，应记录告警而非认定所有事实均获验证。 |
| 标签证据不足的新表达 | 比较事实正确；明确表示现有资料未定义 0/1 的临床编码 | 诚实部分回答，不计为已解决标签知识缺口。 |

自动最低契约 6/6；人工分类为 3 条未见主要语义问题的完成、1 条主任务完成但含扩展告警、1 条诚实部分回答、1 条漏答。不能把诚实部分回答当成知识问题完全完成，也不能改原自动评分消除人工差异。

共 12 次真实 LLM 请求，输入 21,590、输出 2,872，总计 **24,462 Token**，未知 usage 请求 0。六条均 Router＋Finalizer，两次修复路径未在这轮云端回答中触发；其执行与限额由确定性测试证明。小样本延迟不用于简历性能结论。
