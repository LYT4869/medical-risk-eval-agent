# Agent 可靠性修复与定向回归（2026-09-14）

## 结论

本轮落实上一轮的三项优先修复：紧急表达、缺失目标／历史澄清、正文引用协议。保持现有 Structured Router Schema、Workflow 与 Open Agent 分工，没有新增模型、Executor 或 Reflection 子系统；不切默认、不合并、不推送。

6 条已揭晓定向场景在真实 `qwen3.7-plus-2026-05-26` 下完成，自动最低契约和单人人工语义检查均通过。**这不是整体成功率 100%，不替换原 48 场景成绩。** 原比较报告见[真实 Router 对照](independent-router-execution-evaluation.md)。

## 问题与最小修复

| 问题 | 根因 | 处理方式 |
|---|---|---|
| 突然出血、快晕倒被问样本索引 | 紧急判断要求额外的“现在／正在”时间标记 | 补充突发／刚发生的时间概念；否定、历史、假设和教育内容按局部作用域排除，剩余当前症状有限聚合。 |
| 科普或历史词掩盖当前症状／被当作当前症状 | 整句上下文过滤或“我现在”未绑定症状 | 当前标记须与症状有关；历史限定发生在报告前；后续救护车条件不能抹掉先前真实报告。分句表达出血和晕厥仍能合并。 |
| 上次解释缺历史却说无法比较 | 所有 insufficient-history 共用比较文案 | 根据目标输出“没有可定位的上一次预测”；不把依赖查询中唯一当前记录作为上次结果引用。 |
| 给了合法 ID 还机械澄清 | Router 的 missing-target 优先于候选绑定 | 仅单一 explicit 目标、来源候选有效时消解该 missing 状态；歧义仍澄清、非法候选仍拒绝。真实存在与访问权限继续由 C++ 查询决定。 |
| 请求凭据进入开放规划 | 列出动作与 Capability 凭据目标未覆盖 | 补入现有凭据概念判断；前置拒绝，不运行 Router 或领域 Tool。 |
| 正文截短 ID 被跳过 | 正文只匹配完整 ID，截短／加后缀不参加校验 | 先识别可见候选并校验完整语法；完整未知 ID 保留不可用错误语义。格式问题最多修复一次，只列允许 ID，不推断截短 ID 指向谁。 |
| 正文出现 grounding 协议字段 | 内部字段不一定在行首，也可能带引号 | 拒绝正文中的行首、内联和带引号协议字段，复用现有无 Tool Finalizer 修复；不原样输出非法正文。 |

紧急提示只要求联系当地急救或急诊，不推导诊断、不提供治疗。该提示方向参考 [NHS 产后早期说明](https://www.nhs.uk/pregnancy/labour-and-birth/early-days/) 中产后突然大量出血、晕厥／头晕应立即求助的建议；不是项目自行制定医疗处置方案。
