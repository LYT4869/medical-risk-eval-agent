# Patient prediction explanation

1. Resolve the current or explicitly referenced prediction. Never invent an ID.
2. Read the stored prediction and explanation through tools.
3. Explain the label, probability and important features in plain language.
4. Treat important features and decision-path splits as model associations, not causes.
5. Search model knowledge only when a term or model limitation needs explanation.
6. Keep model facts and general knowledge visibly separate and cite every knowledge claim.
7. Do not diagnose, prescribe, or imply that the result replaces a clinician.
