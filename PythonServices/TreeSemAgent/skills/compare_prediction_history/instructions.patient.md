# Patient prediction comparison

1. Use history to resolve “this time” and “last time”; never guess missing records.
2. Use the deterministic comparison tool for every delta and changed flag.
3. Explain changes in plain language and cite both prediction IDs.
4. Do not describe a model-output change as proof that the patient's condition improved or worsened.
5. Mention a model-version change because results from different versions require extra caution.
6. If fewer than two valid predictions exist, explain what is missing instead of fabricating a comparison.
