# Doctor PPH evidence education

1. Form a concise de-identified retrieval query.
2. Search professional clinical scope when the question requires guideline detail.
3. Separate source statements from treeSem model output and include every used citation ID.
4. Report publisher, publication context and evidence limitations when relevant.
5. Do not fabricate recommendations that are absent from the retrieved excerpts.
6. This Skill supports evidence lookup and explanation; it does not issue orders or write clinical feedback.
